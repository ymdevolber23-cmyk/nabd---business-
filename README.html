دليل تشغيل النموذج

واجهة تشغيل عربية داكنة مبنية ضمن نطاق المخطط المرفق. ملف التطبيق مستقل: يحتوي HTML وCSS وJavaScript والصور اللازمة بداخله.

التشغيل

فك ضغط الحزمة، ثم افتح index.html في متصفح حديث. لا يلزم تثبيت حزم أو تشغيل خادم، ولا توجد ملفات صور أو إعدادات جانبية مطلوبة.

ما يتضمنه الـDemo

  • لوحة النظرة العامة ومؤشرات التشغيل والجدول اليومي.
  • وحدات المواعيد والعملاء والخدمات والموظفين والتقارير.
  • الإعدادات ومركز المساعدة.
  • إضافة سجلات تجريبية، تغيير حالات المواعيد وتفعيل الخدمات، والبحث والتصفية وتصدير CSV.
  • تُحفظ التعديلات محليًا داخل المتصفح فقط عند تفعيل خيار الحفظ.

حدود النسخة

هذه نسخة واجهة Demo ثابتة وليست نظام تشغيل متصلًا. الأسماء والقيم بيانات عرض توضيحية. لا يوجد API أو قاعدة بيانات أو مزامنة، ولا تُرسل البيانات إلى خادم.
